# Getting help

| You want to | Go to |
|---|---|
| Install or run MBUDDY | [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md) |
| Build the phone app | [docs/BUILD.md](docs/BUILD.md) |
| Understand how it fits together | [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/README.md](docs/README.md) |
| Wire or flash the desk device | [docs/HARDWARE.md](docs/HARDWARE.md) |
| Report a bug | A [bug report](../../issues/new?template=bug_report.yml) with what you did, what you expected and what happened |
| Suggest something | A [feature request](../../issues/new?template=feature_request.yml) |
| Ask a question or show what you built | [GitHub Discussions](../../discussions) once enabled, otherwise an issue labelled `question` |
| Report a security problem | **Privately**: see [SECURITY.md](SECURITY.md). Please do not open a public issue |

Please include your phone or PC model, the Android or Windows version, and the app version (on the phone: Android Settings, Apps, MBUDDY). If it
is about listening or a brain not answering, Settings, Your data, "Problems log" has what the app noticed; copy it into the report
(it stays on your device unless you share it).
